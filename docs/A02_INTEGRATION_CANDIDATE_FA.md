## قرارداد CI این شاخه

با یک workflow واحد، آزمون Node، ساخت Frontend، ممیزی وابستگی‌های تولید، آزمون Windows PowerShell هر چهار مرحله SQL/ZIP، آزمون واقعی **داده ساختگی** روی موتور LocalDB، ساخت NSIS ویندوز و آزمون ارتقای native روی ماشین مجازی اجرا می‌شوند. سبز شدن این موارد فقط صحت همین دامنه را ثابت می‌کند.

## مانع‌های واقعی برای تحویل به کاربر

1. ارائه رسانه آفلاین رسمی **SQL Express** با نسخه/ویرایش و manifest کامل مورد تأیید ناشر، EULA و نصب کنترل‌شده؛ بدون آن `Mode Install` مسدود باقی می‌ماند.
2. اعتبارسنجی نسخه و `RESTORE VERIFYONLY` و سپس **Restore واقعی بکاپ همین مالک** روی SQL اختصاصیِ خصوصی؛ بازیابی واقعی هنوز `NOT_RUN`.
3. استخراج ساختار SQL واقعی هلو و شناسایی جداول/ستون‌ها بدون آپلود اطلاعات به GitHub؛ پیاده‌سازی آداپتور نسخه‌دار.
4. تطبیق ریال/تومان، اسناد بدهکار/بستانکار، اشخاص، کالا و انبار، فاکتورها، چک‌ها، وجه نقد/بانک و مانده‌های افتتاحیه، سپس rollback و تأیید حسابدار.
5. اتصال قطعات فنی به **ویزارد واقعی با کمترین دخالت کاربر**، تست تمیز/آفلاین/نصب مجدد و تأیید مستقل C1/C2/C3.

این شاخه یک PR Draft است. نه رکورد مالی به مخزن منتقل شده، نه SQL Server روی سیستم کاربر نصب شده، نه بکاپ هلو در مقصد وارد شده است.
