# Factor-easyPro 2.0.0

نرم‌افزار فاکتور، خزانه، انبار و حسابداری دوبل فارسی برای ویندوز ۶۴بیتی؛ مبتنی بر Tauri 2، Vite و IndexedDB، با امکان کار آفلاین.

## دریافت و نصب
نصب‌کننده ویندوز در **GitHub Releases** قرار دارد:
https://github.com/davoodmehraban89/Factor-easyPro/releases

فایل `Factor-easyPro_2.0.0_x64-setup.exe` را دریافت و اجرا کنید. نسخه منتشرشده با پایگاه داده خالی توزیع می‌شود؛ هیچ داده واقعی یا نمونه مشتری داخل فایل نصب نیست. فایل نصب در این انتشار امضای کد تجاری ندارد، بنابراین هش SHA-256 آن را با بخش Release مقایسه کنید.

## شروع به کار
1. برنامه را باز و رمز مدیر را تعیین کنید. رمز اولیه عمومی وجود ندارد.
2. از منوی **حسابداری**، دوره مالی شمسی مربوط به سال جاری را تعریف کنید.
3. در «کدینگ حساب‌ها»، **ایجاد کدینگ پیشنهادی** را انتخاب کنید.
4. در زبانه «عملیات یکپارچه و انبار»، ثبت یکپارچه را برای شرکت خالی فعال کنید؛ انبار و صندوق اولیه با مانده صفر ایجاد می‌شوند.
5. کالا و طرف‌حساب بسازید؛ ابتدا فاکتور خرید برای ورود موجودی و سپس فروش، تسویه، گزارش و انبارگردانی را اجرا کنید.

**توجه:** فعال‌سازی یکپارچه برای شرکتی که از قبل فاکتور/انبار/خزانه و مانده افتتاحیه دارد، به‌طور خودکار انجام نمی‌شود تا داده‌های تاریخی مغایر نشوند. برای نصب پاک، اطلاعات برنامه قدیمی را فقط پس از اطمینان از عدم نیاز حذف کنید.

## ماژول‌ها
- صدور فاکتور فروش و خرید، پیش‌فاکتور، مرجوعی با اتصال به فاکتور اصلی و شماره‌گذاری قابل تنظیم.
- جستجوی کالا و طرف‌حساب، موجودی به تفکیک انبار، ارزش‌گذاری میانگین موزون و انبارگردانی.
- دریافت و پرداخت، تسویه جزئی، حساب‌های صندوق و بانک، چک، هزینه و درآمد.
- کدینگ چندسطحی، دوره مالی، سند دستی، دفتر کل، تراز آزمایشی، سود و زیان و ترازنامه.
- پشتیبان رمزگذاری‌شده با AES-GCM و قابلیت بازیابی در محدوده شرکت فعال.
- مدیریت کاربران و مجوزها. صدور اسناد دستی و تغییر ساختار حسابداری فقط برای مدیر مجاز است.

## راهنمای توسعه
```bash
npm ci
npm test
npm run build
npm exec tauri build
```

سیستم توسعه Windows به Node.js و Rust / ابزارهای Tauri نیاز دارد. تست‌ها از `fake-indexeddb` استفاده می‌کنند و اطلاعات واقعی کاربر را تغییر نمی‌دهند.

## ملاحظات
- مبالغ حسابداری به ریال صحیح و مقادیر کالا تا سه رقم اعشار نگهداری می‌شوند.
- مرورگر/IndexedDB برای یک سیستم آفلاین محلی طراحی شده است؛ این نسخه سرور چندکاربره هم‌زمان نیست.
- چاپ رسمی به معنی تایید حقوقی مالیاتی یا ارسال خودکار به سامانه مودیان نیست. قوانین مالیاتی را با حسابدار بررسی کنید.
- لایسنس/نسخه آزمایشی فعلی سقف استفاده دارد؛ شرایط آن در خود نرم‌افزار نمایش داده می‌شود.
- اطلاعات IndexedDB در حالت عادی رمزگذاری سراسری نیست؛ امنیت سیستم‌عامل، حساب ویندوز و نسخه پشتیبان ضروری است.
- نصب‌کننده امضای دیجیتال تجاری ندارد و باید از صفحه اصلی Release دریافت شود.

مستندات پروژه: `V2_THREE_PHASE_PLAN.md` و `V2_PHASE2_DELIVERY.md`.
